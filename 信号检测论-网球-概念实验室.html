①两个分布与判定标准

横轴是落点余量：以底线为 0，正数=球落在界内多少米，负数=出界多少米。 界外球和界内球各是一团分布，你可以把它们拉开（提高 d′），也可以把判定标准这条竖线左右挪（改变 c）。 竖线右边的球你挥拍，左边的你放掉——四条曲线下的面积，就是你结果页上的 H / M / FA / CR。

②ROC 曲线

同一个 d′ 只对应一条 ROC 曲线；拖动判定标准，你只是沿着这条曲线滑动。 想换一条曲线，只能改 d′。这就是结果页那句"d′ 是能力，c 和 β 是偏向"的图像版。

约定：改 σ(SN) 时，我把直线固定在 z(FA)=0（即 P(FA)=0.5）那一点上转动， 所以"中位敏感度"不变、只改两分布的方差比。等方差时 σ(SN)=σ(N)，斜率 1，于是 ROC 关于负对角线对称。

怎么读

右上角是完美，对角线是瞎猜。曲线离对角线多远 = d′； 点在这条曲线上的位置 = c。两个玩家 d′ 一样，曲线完全重合，但可以停在这条曲线的不同位置上。

③标准与奖惩 · 最优标准在哪

到目前为止你都把 c 当成"你自己定的"。但最优点不是随便定的：它由先验（对手的球有多少比例落在界内） 和奖惩（漏一个球 vs 挥空一次，各值多少）共同决定。

β_opt = [ P(N) / P(S) ] × [ ( V(CR) + C(FA) ) / ( V(H) + C(M) ) ] c_opt = ln(β_opt) / d′

（Tanner & Swets 的写法：C(·) 填"代价"的正数，V(·) 填"收益"的正数。）

网球里的一个诚实的麻烦

纯按比分算，网球是对称的：漏掉界内球丢一分，挥空一个界外球也丢一分，两边的代价一样。 所以单靠比分，β_opt 只等于 P(N)/P(S)，c 只会被先验推走。

真正让最优标准偏离中性的，是那些没写进比分表的代价：关键分上漏一个球的心理冲击、 长盘里每一次挥拍消耗的体能、发球上网时"挥空也无所谓"的主动权。 上面四个预设做的就是把这些隐性代价换算成等价的收益矩阵——不是字面比分。

方向怎么记

漏报代价变大（关键分）→ β_opt 变小 → c_opt 变小 → 更冒进，宁可挥空。
虚报代价变大（体能吃紧）→ β_opt 变大 → c_opt 变大 → 更保守，宁可放掉。
P(S) 变大（对手的球大多在界内）→ β_opt 变小 → 更冒进。

模型说明（请照实讲）

这是一个教学示意模型，不是实测数据。参数（d′ 每场掉 0.8、主观 P(S) 每时段向"记住的信号比例"靠拢 25%） 是我为了把机制演示清楚而选的示意值，没有对应的实验文献标定。 每次模拟都带抽样噪声——同一组设定按两次"开始模拟"，曲线不会完全一样，这本身也是 SDT 的一课： 小样本下的 d′ 是个很不稳的估计量（详见《结束页面详解》第 6 节）。

漂移那一栏用的规则是 记住的信号比例 = (H + 2.5·M) ÷ (3.5·nS)， 即漏报在心里留的痕迹比正确拒绝重得多。它的关键性质是不会失控： 标准偏保守→漏报变多→主观 P(S) 更低→标准更保守，但反过来标准过分保守时击中率会掉， 主观 P(S) 又会被拉回来。两股力方向相反，于是主观 P(S) 停在一个稳定值上 （开局 d′=1.5、c=0 时约在 P(S)≈0.42，对应 c≈+0.23）。 从完全中性的 c=0 出发，你会自己漂到一个偏保守的稳定标准上——这就是 Baker 期望理论想说的那件事。

对策清单（从参考站的"阻止技术"翻成网球）

  • 分与分之间固定例行动作：拍两下球、走到固定位置——用外显的仪式撑住内部唤醒。
  • 呼吸：发球前一次慢呼气，直接压唤起水平。
  • 局间休息补水补糖：d′ 的衰减有一半是生理的，不是意志问题。
  • 盯球缝线，而不是盯落点：把判断建立在一个更稳的知觉特征上，等于自己给自己降 σ。
  • 目标样例：赛前看几个贴线球的慢放，把"压线球长什么样"重新校准一遍。
  • 降低节奏：擦汗、走位、多要一个球——把事件率降下来，给每个判断留出时间。
  • 局间教练反馈：外部反馈是打断"漏报 → 更保守 → 更多漏报"这个循环最直接的手段。
  • 置信水平报告：逼自己每次判断后给个 0-100 的把握度，把内隐的标准外显出来。
  • 间歇第二任务：球与球之间安排固定小动作，维持唤醒而不是让它掉下去。
  • 缩短回合：每多一拍就多一次判断，决策次数本身就是消耗品。

⑤人 vs 鹰眼 · 电子司线

现在把另一个检测器放到同一张 ROC 上：机器。它判的不是"球会不会落在界内"， 而是"球已经落地了，它落在哪"——同一套 SDT 语言，完全不同的任务难度。

为什么机器那么强，但两边的 d′ 不能直接比

它是真的准

鹰眼对外宣传的精度是误差 2.6 mm 以内；厂商自己的说法是平均误差 3.6 mm。 而网球直径 67 mm——也就是说它的平均误差大约是球径的 5%。 2021 年澳网是第一个全面用 Hawk-Eye Live 取代司线的大满贯，美网 2022 年跟进，温网从 2025 年起全面电子司线。

红土（法网）长期不用鹰眼，理由是球痕可见——换了一套更便宜、更直观的技术。

但它也不完美，而且它的任务更简单

2007 年温网有一球鹰眼判"界内 1 mm"，这个距离小于它自己标称的 3.6 mm 平均误差。 2008 年有论文批评它从不显示误差范围，制造了一种虚假的精确感。

更关键的是：你的任务和它不是一个任务。它的球已经落地了、有十台摄像机、没有时间压力。 你要在球落地之前预判，还要对抗视觉噪声和那条正在缩短的节奏条。 所以上面那张图里两条曲线的差距，一部分是"能力"，更大一部分是"题目不同"——这个 d′ 差不可直接解释为人的能力差。

换算一下：鹰眼的误差折成 d′ 是多少

把"判界内/界外"当成一个 SDT 任务：两团分布的分离就是球的落点离底线多远（典型值取 1 m）， 噪声就是机器自己的测量误差。于是 d′ ≈ 2 × 离线距离 ÷ 测量误差。

机器的测量误差（mm）3.6
典型离线距离（m）1.00

算出来的 d′ 是三位数——在"判界内/界外"这个任务上，机器早就到天花板了。 这也是为什么司线争议的重点根本不是"它准不准"，而是要不要把它自己的不确定度显示给人看： 一个 d′ 极高的检测器仍然有 c，而它的 c 是厂商和赛事方定的，不是球的属性。

常见坑

坑说明
单轮 d′ 封顶在 2.93 12 球设计下 nS = nN = 6，加上 0.5 对数线性校正，z 的取值被夹在 ±1.4652， 于是单轮 d′ 只可能落在 [−2.93, +2.93]。打出 2.93 的意思是"这一轮我没给出可估的差别"， 不是你刚好那么强。
零格必须校正 H / M / FA / CR 里只要有一格是 0，z 就会发散。游戏用 0.5 对数线性校正 （Hautus 1995）给个有限值，结果页会写明"已用校正估算"。
β 不能跨难度比 因为 β = exp(d′·c)。同一个 c，换个 d′ 就换个 β。 要比"偏向"，跨难度只用 c。
从不挥拍也能出数字 P(H) = 0、P(FA) = 0 → d′ = 0、A′ = 0.5、c = +1.465。 看起来"没有分辨力且极度保守"——正确，但那是没数据，不是没能力。
d′ 属于"你 + 这一档难度" 换个难度，你的 d′ 就变。它不是你的固有属性， 是"你的知觉噪声"和"这档难度的落点分离"之比。
